LightGBM Model – lgb_xauusd_multi_tf.txt (~5.3 MB)
=====================================================

HOW TO ADD THE TRAINED MODEL (ca. 2 Minuten):

1. Download from the chat:  lgb_xauusd_multi_tf.txt

2. Open this page in the browser:
   https://github.com/meffyou226-oss/Meffs/upload/main/ml_strategy/model

3. Drag & drop the file lgb_xauusd_multi_tf.txt into the page

4. Commit message: "Add trained LightGBM model"

5. Click "Commit changes"

Danach ist alles komplett. Start:

  cd ml_strategy
  pip install -r requirements.txt
  python code/strategy_backtest.py \
    --m15_dir ../data/xauusd_m15 \
    --h1_dir  ../data/xauusd_h1 \
    --m5_dir  ../data/xauusd_m5 \
    --lot 0.05

Das Modell erwartet die Feature-Liste aus feat_cols.json.

# BTCUSD M15 (Dukascopy BID)

15-minute candles from Dukascopy Bank datafeed.

- Instrument: BTCUSD
- Timeframe: M15
- Price: BID
- Range: 2022-01-01 to 2026-08-30 (UTC)
- Format: `timestamp,open,high,low,close` (Unix milliseconds)
- Files: `BTCUSD_M15_YYYY_MM.csv`

Source: `dukascopy-node` / `datafeed.dukascopy.com` (`btcusd`, timeframe `m15`).

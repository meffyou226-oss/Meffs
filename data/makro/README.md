# XAUUSD Makro-Daten (4 Jahre)

Stand Abruf: 2026-08-28.

Quellen: FRED (St. Louis Fed) + Yahoo Finance (COMEX GC=F, ICE DXY, SI=F).

## Dateien

| Datei | Inhalt |
|---|---|
| `xauusd_macro_daily_YYYY.csv` | Tagesdaten nach Jahr: Gold, DXY, VIX, Treasuries, TIPS-Realzins, USD-TWI, Risiko |
| `xauusd_macro_weekly.csv` | Initial Claims, Fed-Bilanz (WALCL) |
| `xauusd_macro_monthly.csv` | CPI/PCE YoY, NFP, UNRATE, M2 + Monatsschlusskurse |
| `xauusd_macro_dashboard.csv` | Letzter Wert je Serie |
| `xauusd_macro_katalog.csv` | Serien-IDs und Quellenlinks |

Sample: 2022-08-01 bis 2026-08-28.

Gold-Proxy ist COMEX Front-Month (`GC=F`), nicht LBMA-Fix.
Excel-Workbook lokal: `Meffs_Makro_Daten_XAUUSD.xlsx` (Dashboard + Charts).

# BTCUSD M5 (Dukascopy BID)

5-minute candles from Dukascopy Bank datafeed.

- Instrument: BTCUSD
- Timeframe: M5
- Price: BID
- Range: 2022-01-01 to 2026-08-30 (UTC)
- Format: `timestamp,open,high,low,close` (Unix milliseconds)
- Files: `BTCUSD_M5_YYYY_MM.csv`

Source: `dukascopy-node` / `datafeed.dukascopy.com` (`btcusd`, timeframe `m5`).
